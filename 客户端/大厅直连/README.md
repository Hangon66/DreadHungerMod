# 修复大厅卡加入（房主安装）

实现大厅房间通过IP直连加入，不使用EPIC中继服务，将本地7777游戏端口自行穿透到公网
即可修复大厅卡加入问题，不受EPIC服务连接问题影响
只需房主安装，加入方无需任何改动。
注意：若未启动穿透，则需ENABLE修改关闭脚本，恢复原大厅p2p连接逻辑

## 文件

- `[大厅补丁]大厅直连_热重载.js`
- `[大厅补丁]大厅直连_热重载.config`（必须与 `.js` 同名同目录）

## 使用

1. 把上面两个文件放进：
   `DreadHunger\Binaries\Win64\Patches\`
2. 打开脚本，改开头两项：
   ```js
   var TARGET_IP   = '你的公网IP或域名';
   var TARGET_PORT = 12226;
   ```
3. 配置穿透或端口转发：
   **公网 UDP 12226 → 房主本机 UDP 7777**（UDP，不是 TCP）
4. 重启游戏（或等热重载），**回主菜单重新创建大厅**
5. 加入方输入 `公网地址:12226` 即可加入

## 开关

| 变量 | 默认 | 说明 |
|---|---|---|
| `ENABLE` | `true` | 总开关，`false` 完全失能并还原 |
| `TARGET_IP` | `'43.226.61.35'` | 发布地址，支持域名；留空 `''` 则自动解析（仅 IPv4） |
| `TARGET_PORT` | `12226` | 发布到房间的公网端口 |
